# ADApose web

Next.js (App Router, TypeScript, React), Tailwind + shadcn/ui, TanStack
Query/Table + Server Components (no Redux). A Server Component queries a
real Postgres DB (Supabase, via Drizzle — `src/db/schema.ts`) directly —
`current_readings` is what the pool comparison page actually reads, kept
fresh by a pipeline that spans two directories: Python measurement in
`automation/sqrtk/`, Node ingest/refresh in this project's own `scripts/`
(`web/scripts/` from the repo root) — rather than by reading local files at
request time. Full reasoning: `docs/decisions.md` D29.

First slice, per D28: a cross-DEX LP pool discovery/comparison view (TVL,
volume, √k-based fee APR) is built and reading real data (Minswap-only so
far). Wallet connection (CIP-30 discovery, `@spacebudz/lucid`, a modal
picker) is built and working — no position creation, no zap-in yet.
Reference architecture for the general app shape: FUM
(`~/code/fum_project`, a separate local project, already runs Next for a
directly comparable DeFi frontend) — its EVM-specific dependencies don't
transfer. The Cardano wallet/tx-building layer's WASM/ESM/SSR friction,
flagged speculatively in D29's original addendum, is now resolved in
practice — see `docs/decisions.md`'s D29 addenda (2026-08-03) for the
Turbopack-specific findings and the CIP-30 `isEnabled()` gotcha.

`AGENTS.md` in this directory (auto-generated by `create-next-app`) flags
that the installed Next.js version may have API/convention changes past an
LLM's training data — check `node_modules/next/dist/docs/` before assuming
prior Next.js knowledge still applies.

## Running it

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Edit `src/app/page.tsx`
— the page auto-updates. `npm run build` runs the full production build
(type-check + lint + Tailwind + Next's own pipeline) — the fastest way to
verify the whole setup is coherent without a browser.
